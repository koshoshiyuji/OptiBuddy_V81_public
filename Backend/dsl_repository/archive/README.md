# archive/

このフォルダには、特定の過去の一回限りの作業（データ移行・バグ修正の後始末・
実験シナリオの登録など）のために書かれ、既に役目を終えたスクリプトを集めている。

- 現役の開発・保守ツール（`cleanup_domain.py`、`dashboard.py`、
  `export_scenario.py`、`lint_field_consistency_all_domains.py`など）は
  `dsl_repository/` 直下に残っている。
- ここにあるスクリプトは、実行当時は正しく動作したが、対象の作業（特定バグの
  一度きりの修正、特定シナリオの登録、特定ドメインの削除など）が完了済みで、
  以後再実行する想定がないもの。
- 何をいつ・なぜ行ったかの記録は各スクリプトのdocstringおよび
  `docs/ENGINEERING_LOG.md` を参照。
- パッケージ配布時は、このフォルダごと除外する想定（2026-07-20 整理）。
